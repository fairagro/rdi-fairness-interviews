Semantic Lookup Platform

SemLookP is a semantic lookup and ontology integration service supporting FAIR metadata annotation and search in the life sciences. It is built on the EBI Ontology Lookup Service (OLS) and Ontology Xref (OxO) mapping tool. SemLookP provides access to key standardized ontologies for annotating human, mouse and rat omics data and clinical data, and includes terminologies for genes, gene variants, transcripts (mRNAs/miRNAs), and proteins. A mapping service connects concepts across different vocabularies, allowing researchers to semantically annotate data and literature in an unambiguous, interoperable way
