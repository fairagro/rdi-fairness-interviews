# FAIRagro RDI FAIRness Assessment Survey & Scoring Framework

This repository contains the core methodology, operationalized survey schema, automated scoring code, and data artifacts for evaluating the FAIRness of Research Data Infrastructures (RDIs) within the German agrosystem research landscape.

This framework moves beyond high-level theoretical guidelines by operationalizing the **RDA FAIR Data Maturity Indicators** into a reproducible, multi-dimensional scoring methodology tailored for the FAIRagro consortium.

---

## Overview

The framework assesses decentralized, federated repositories across 20 core technical metrics distributed equally across the four foundational pillars of FAIR:

**Findability (5 metrics):** Evaluates persistent identifier assignment, metadata richness, schema standardization, and discoverability.


**Accessibility (5 metrics):** Assesses data retrieval protocols, authentication mechanisms, and persistent metadata availability.


**Interoperability (5 metrics):** Examines formal knowledge representations (ontologies/RDF), controlled vocabularies, and machine-actionable APIs.


**Reusability (5 metrics):** Checks legal data licenses, provenance information, documentation quality, and citation guidelines.



Rather than utilizing a single composite score which can mask specific technical bottlenecks, this framework uses a **granular, 5-point feature-scale rating per pillar**. This multi-dimensional approach provides infrastructure providers with a transparent, "FAIR-by-design" roadmap for optimization.
